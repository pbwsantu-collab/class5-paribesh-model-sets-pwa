# Class 5 Paribesh Model Sets – Interactive PWA

**English translation of all 30 Model Question Sets** from *Tulsir Prashnasangi Right Track – Class 5 (Environmental Studies)*.

## Features
- ✅ All 30 Model Sets combined
- ✅ Intact original format (sections, numbering, options, school names)
- ✅ **Clickable answers** – click any question or option to reveal the answer
- ✅ Side menu to jump between sets instantly
- ✅ **Exam Mode** – hides all answers + starts 1 hour 30 min countdown timer
- ✅ Fully offline-capable Progressive Web App (installable on phone/desktop)
- ✅ Responsive design (mobile-first)

## How to use
1. Open the site (or install as PWA)
2. Use the ☰ menu to select any Model Set 1–30
3. Click a question / option → answer appears
4. Toggle **Exam Mode** for timed practice without answers
